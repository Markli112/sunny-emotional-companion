# 记忆与隐私

> Sunny 的设定是 "Safe & private"。隐私不是标语，而是**默认不记、记什么由用户决定、随时可删**。

## 1. 默认策略

| 数据类型 | 默认 | 说明 |
|---|---|---|
| 当前会话上下文 | 保留 | 会话结束丢弃，除非用户同意长期记忆 |
| 原始录音 | **产品不落盘** | 唤醒词本地处理；ASR 供应商按合同零/短期保留 |
| 完整逐字稿 | **不保留** | 只保留结构化摘要/记忆卡片 |
| 长期记忆 | **需明示同意** | 首次写入前询问；可查看/删除 |
| 安全计划 | 需同意，本地加密 | 危机时优先可用；用户可改 |
| 风险事件记录 | 最小化保留 | 仅时间、等级、动作、交接 |
| 生物特征/声纹 | **不做** | 不用于识别身份 |
| 用于训练 | **默认不** | 未单独同意不得训练/微调 |

---

## 2. 可以记什么

只记"下次能陪得更好"的信息：

| 类型 | 例子 | TTL 建议 |
|---|---|---|
| `preference` | 不喜欢被叫"宝宝"；喜欢慢语速 | 直到用户修改 |
| `soothing` | 长呼气/雨声/安静陪着更有效 | 90 天，可续 |
| `event` | "下周三答辩""最近在准备秋招" | 30 天 |
| `person` | "室友小 A""导师"（只记称呼） | 30 天 |
| `boundary` | "不要主动提体重""不想聊家里" | 直到用户修改 |
| `safety_plan` | 预警信号、可联系的人、热线 | 直到用户撤销 |

**不记**

- 精确地址、身份证、银行卡、密码、位置轨迹。
- 性取向、性别认同、健康诊断、被侵害细节——除非用户明确要求且与安全计划直接相关，且本地加密。
- 第三方的敏感信息（室友/家人的隐私）。
- 原始录音、完整逐字稿、可还原的对话日志。
- 任何"用户没同意"的推断（如"她应该是抑郁"）。

---

## 3. 写入前必须同意

> "我可以记住这一点，下次更好地陪你吗？你可以随时让我忘掉。"

用户没有明确说"可以"时，`memory_write` 必须是 `null`。不要用"沉默=同意"。

记忆卡片示例：

```json
{
  "type": "preference",
  "content": "不喜欢被叫宝宝；难受时希望语速慢一点",
  "ttl_days": 365,
  "consent": true,
  "created_at": "2026-11-02T00:00:00+08:00"
}
```

---

## 4. 用户控制

用户应该能：

- **查看**："你记得我什么？" → 用简短、可读的列表复述，不暴露内部 ID。
- **删除**："忘掉我刚才说的""把关于我室友的都删掉" → 确认范围，执行，告知"已经删了"。
- **关闭**："以后别记了" → 停止写入；已有记忆是否保留要问。
- **导出**：App 内提供记忆导出（JSON/文本）。
- **撤回同意**：随时；不影响已发生的安全记录（按法律要求）。

**查看话术**

> "我记得三件事：你不喜欢被叫宝宝；下周三有答辩；难受时慢一点说话更有用。要我删掉哪条吗？"

**删除话术**

> "好，关于答辩的那条我删掉了。其他的要一起删吗？"

不要假装删除；如果因为安全/法律必须保留，明确说明保留什么、为什么、多久。

## 5. 第三方 AI 数据流

```text
麦克风 → 本地唤醒/VAD → ASR（本地或云端）→ 编排后端 → 第三方 LLM → TTS → 扬声器
```

**最小化**

- 只发当前轮 + 必要状态摘要；不要每次发全部历史。
- 姓名/学校/地址先做占位替换（"小 A""某 985"）。
- 长期记忆以结构化卡片注入，不注入原始逐字稿。
- 关闭第三方侧的"训练/改进"选项（如合同允许）。
- 明确告知用户：语音会经过第三方 AI 处理；跨境传输需单独同意。
- L2/L3 对话尽量走合规的人工/境内链路，不发给未签约的第三方。

**供应商清单**（产品文档维护）

| 供应商 | 用途 | 数据 | 保留期 | 跨境 | 合同 |
|---|---|---|---|---|---|
| ASR | 语音转文字 | 音频/文本 | 0–7 天 | 是/否 | DPA |
| LLM | 对话 | 文本+状态 | 0 天（零保留） | 是/否 | DPA |
| TTS | 语音合成 | 文本 | 0 天 | 是/否 | DPA |

## 6. 安全与工程

- 传输 TLS 1.2+；服务端静态加密；密钥不进机器人固件。
- 访问最小权限；客服查看对话需二次授权 + 审计日志。
- 日志默认脱敏；保留 7 天排障；安全事件按合规期限。
- 设备本地记忆加密；恢复出厂设置彻底擦除。
- 唤醒词本地识别；麦克风硬件静音；明确指示灯。
- 记忆检索按用户 ID 隔离；防止提示词注入越权读取。

---

## 7. 未成年人

- 默认不写入长期记忆，除非监护/合规允许且有必要。
- 不记录可识别身份的信息。
- 涉及虐待/忽视：按当地儿童保护法律处理；不承诺保密。
- 面向未成年人需单独隐私政策、监护人同意和内容分级。

---

## 8. 保留与删除（建议）

| 数据 | 保留 |
|---|---|
| 原始音频 | 不保留（或 ≤24h，仅排障，加密） |
| ASR 文本（临时） | ≤7 天 |
| 会话摘要 | 30 天，除非用户保存 |
| 长期记忆 | 用户设定 TTL；默认 90 天，可续 |
| 安全计划 | 直到用户删除/账号注销 |
| 风险事件 | 按法律/合规；建议 1 年，最小化 |
| 排障日志 | 7 天，脱敏 |
| 账号注销 | 30 天内删除/匿名化，法律要求除外 |

## 9. 隐私话术

**首次使用**

> "我会尽量少记。默认只记这次对话，结束后就忘。如果你想让我记住一些偏好，我会先问你。"

**"你会告诉别人吗"**

> "不会随便告诉别人。但如果你正处在危险里，我需要帮你联系能真正帮到你的人。具体记了什么，你可以在 App 里看和删。"

**"你在录音吗"**

> "默认不录。我需要听清你说话时，麦克风会亮；原始录音不会保存。"

**要求删除**

> "好。我现在删掉关于这件事的记忆。安全计划里如果要保留一条'不要提这件事'，你希望保留吗？"
